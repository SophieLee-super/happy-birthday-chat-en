# Changelog

Every version of this project stays reachable — updates are always new commits on top, never rewrites, and milestone versions are kept as GitHub Releases so any older version can be downloaded exactly as it was.

## v1.0 — 2026-11-18 · first release of the English edition

- Full English version of the site: chat script, generated special act, letter, and all UI text
- Based on the main project's v6 (date-driven generation, carnation photo, Hamilton / Cage same-day cards, no zodiac or birthstone screens)
- Default birth date set to 2000-01-01 as a clean template default; a `?date=` in the link overrides it

> The main project's full iteration story (v1 → v6) is recorded in the CHANGELOG of the happy-birthday-chat repository.
